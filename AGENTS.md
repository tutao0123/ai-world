# AI World

Independent interactive AI learning demo created by Tao, with Xiaotao as the guide.

- Read README.md and docs/learning-model.md first. This project is separate from the TAO55s episode pipeline.
- Curriculum source: docs/source-mapping.md and docs/source-manifest.json. Full v1.0.4 extracts under docs/sources/ are optional local inputs, not distributed. Preserve all 13 chapters / 101 source topics in both languages. Treat summaries and quizzes as adaptations, not verbatim source or refreshed external verification.
- src/source-index.ts is generated by scripts/extract-source.py; do not hand-edit it. Source paragraph IDs are version-specific and must be migrated if the document changes.
- English content in curriculum-en-*.ts shares canonical IDs, source anchors, quiz answers and progress with Chinese. Localized UI uses i18n.ts/ui-en.ts; validate both languages after changing visible copy.
- Keep the map central: geography and interactive experiments explain relationships.
- All technical text, diagrams, formulas and labels remain code-native.
- Keep teaching assumptions visible. Memory estimates are not hardware benchmarks or deployment guarantees.
- Preserve the approved Xiaotao appearance. public/xiaotao.png is copied from TAO55s approved v2 neutral asset; see docs/assets.md.
- Each specialist has a task envelope in .coordination/ and may write only in its write_scope. Central project files have one owner.
- Run npm test, npm run build and npm run test:e2e for changes to calculations or the exploration flow.
- No backend, accounts or paid API calls are required for this demo.
- Production is hosted on Vercel project ai-world at https://world.tao55s.com; read docs/deployment.md before publishing updates. Keep source imports, local credentials and test artifacts out of deployments.
