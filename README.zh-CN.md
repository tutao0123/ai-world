# AI World · 跟小淘，探索 AI 大陆

**一张可以走进去的 AI 知识地图。Created by Tao · 向导：小淘。**

拖动地图、打开地标，通过简短解释、具体案例和小实验理解 AI。无需账号、后端或付费 AI API。

[在线演示](https://world.tao55s.com) · [English](README.md)

在线演示对应当前已部署版本。本次源码已实现中英文支持，尚待部署上线。

## 探索地图

知识大陆覆盖 **4 个区域、13 章、全部 101 个原文编号知识点**，每章包含三个要点与一道理解挑战。

| 区域 | 章节 |
| --- | --- |
| 模型起源大陆 | 1 AI 系统坐标 · 2 机器学习 · 3 神经网络与 Transformer · 4 模型训练生命周期 |
| 应用群岛 | 5 Prompt 与上下文 · 6 RAG · 7 Agent 与工具 · 8 评测与生产化 |
| 技术与治理海岸 | 9 多模态 · 10 基础设施与开源生态 · 11 安全与治理 |
| 实践远航湾 | 12 AI 编程 · 13 岗位与学习路线 |

- 拖动、缩放地图，点击地标阅读；使用 `Ctrl+K` / `⌘K` 搜索，也支持键盘和触屏操作。
- 选择完整探索、产品与业务、应用开发、算法与模型、系统与基础设施五条路线。章节与知识点支持分享链接。
- 进入五个实验：**Token 村、向量河谷、注意力山脉、大模型之城、量化矿岛**。
- 在探索护照中收集章节与实验印章。印章表示完成这里的挑战，不代表掌握全部知识。

语言选择器支持切换中文与英文，选择保存在当前浏览器。两种语言共享同一份章节和实验进度。首次访问默认跟随浏览器语言；链接中明确指定的 `?lang=en` 或 `?lang=zh` 优先。

本次构建支持用 `/?lang=en` 直接打开英文，`/?lang=en&view=labs` 进入英文实验，`/?lang=en#chapter/c06/6.2` 打开具体知识点。部署本次构建后，线上站点才会提供这些双语入口。

## 本地运行

需要 **Node.js 24+** 和 npm。在仓库根目录执行：

```sh
npm ci
npm run dev
```

打开 [localhost:5178](http://127.0.0.1:5178/) 或 [英文界面](http://127.0.0.1:5178/?lang=en)。开发服务器只监听本机。

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

测试覆盖教学计算、课程合同、翻译和浏览器探索流程。构建执行 TypeScript 检查，并生成 `dist/` 静态网站。浏览器测试使用 Chromium。可用 `npm run preview` 本地预览构建结果；若开发服务器占用同一端口，先停止它。

## 教学边界与来源

课程以 **《AI 入行知识地图》v1.0.4** 为底稿，改编为摘要、案例和问答。完整覆盖章节与编号小节，不是原文全文替代品，也不代表重新核验了所有外部事实。来源关系见[内容映射与来源记录](docs/source-mapping.md)。完整来源档案保留在本地，仓库通过来源清单验证覆盖情况。

地图地理关系是学习比喻。文字切分、二维向量位置、注意力连线与续写选项都是人工编写的教学示意，不是真实模型输出。

量化实验按取整的 70B 参数、Llama 3.1 70B 风格 GQA、FP16 KV 缓存、batch = 1 和假设的 3 GiB 预留估算内存。没有完整建模量化元数据与实际内存峰值；落入教学预算不代表真实部署成功，也不是硬件性能测试。详见[公式与教学假设](docs/learning-model.md)。
