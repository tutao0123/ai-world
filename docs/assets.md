# Asset provenance

`public/xiaotao.png` is a byte-for-byte copy of the approved character delivery asset at TAO55s character asset `public/brand/character/xiaotao/v2/neutral.png`. Source of truth: TAO55s `brand/assets.manifest.json`, `brand/xiaotao-production-guide.md` and `brand/style-guide.md`. It is used as a static guide portrait. No new pose, animation or identity was generated.

The map and all labels are original code-native SVG in `src/world-map.ts`. UI icons are simple inline SVG. Fonts use the operating system's available fonts; the demo does not request external fonts.

This local demo has not been assigned an open-source license. Confirm code and character asset licensing before publishing an open-source repository; character rights need not share the code license.
