## 与第一版实验的关系

原有五个入门实验继续保留：Token、Embedding、Transformer、LLM 与量化。它们连接到相应章节，但新增章节不因此声称已经有完整模拟关卡。当前扩展补足内容覆盖、阅读与章节问答，后续仍可逐章增加交互实验。

量化实验中的显存数字继续属于教学估算，不能当作特定硬件、模型或推理引擎的实测结果。原始完整来源和原有内容资产不由本次改编覆盖。

## 维护方式

更新底稿时重新计算文件哈希，生成带版本的段落提取，并逐项检查课程映射。若前插段落导致编号移动，需要同时更新 `sourceIds`，不能仅替换 JSON 后继续沿用旧引用。章节摘要、问答、实验模型和链接应分别复核，避免把“文件一致”“结构覆盖”和“技术事实已全面验证”混为一个完成状态。


## GitHub 分发与英文版

仓库包含 `docs/source-manifest.json`：源文档哈希、全部段落 ID 与章节标题，用于验证 13 章 / 101 个小节及引用锚点。全文提取与原始 Word 文件留在本地，不随仓库分发。`src/source-index.ts` 是原文术语的生成索引。

英文版是同一份中文课程改编的完整翻译，共用章节、小节与实验 ID、来源锚点和正确答案。英文 sourceHeading 是原文标题的译文，中文 sourceHeading 保留原文。

持有原始文件的维护者可运行 `python scripts/extract-source.py <local-copy.docx> <versioned-copy.docx>` 重新提取与生成清单。此步骤不是安装、构建或运行测试的前提；更新来源版本时需同步审查全部课程和译文。
